
# Sales Forecasting and Business Analytics

## Project Overview
A Python Flask and MySQL application for analyzing historical sales data and forecasting future sales.

## Objectives
- Analyze sales performance.
- Identify monthly sales trends.
- Find top-performing products.
- Store sales records in MySQL.
- Predict future sales using machine learning.

## Technologies Used
- Python
- Flask
- MySQL
- Pandas
- Scikit-learn
- HTML and CSS

## Main Features
- Sales data management
- Business analytics
- Sales forecasting
- Reports and visualizations
